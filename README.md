# Le Registre du Seigneur

Outil gratuit pour les joueurs de **Rise of Lords** : points de classement, armée, siège, arsenal, production,
bilan des investissements, plan d'achats, pillages, prix et simulation de combats – avec profils et historique daté.

Auteur : **lebron23**. Outil non officiel, sans lien avec l'équipe de Rise of Lords.

## Télécharger

➡️ **[Télécharger la dernière version (zip)](../../releases/latest/download/registre-du-seigneur.zip)**
· [toutes les versions](../../releases) · [nouveautés](CHANGELOG.md)

Décompressez le zip, puis :

- **Windows** : double-cliquez sur « Lancer le Registre (Windows).bat »
- **Mac** : double-cliquez sur « Lancer le Registre (Mac).command » (la première fois : clic droit > Ouvrir)
- **Linux** : `python3 start.py`
- **Sans Python** : ouvrez simplement `registre-du-seigneur.html` et utilisez « Enregistrer dans un fichier ».

Tout le mode d'emploi est dans [LISEZMOI.txt](LISEZMOI.txt). Vos données restent sur votre ordinateur
(fichier `rol-data.json`).

## Règles du jeu

Le Registre ne se connecte jamais au jeu : aucune requête au site, aucune action automatique, aucun identifiant
demandé, ce n'est pas un module du navigateur. Toutes les valeurs sont saisies ou collées à la main. Il respecte
la charte du jeu (scripts, add-ons, multis et partage de compte interdits).

## Avertissement

Fourni tel quel, gratuitement. Les formules, prix et valeurs peuvent contenir des erreurs ou changer avec le jeu :
l'auteur ne garantit pas les résultats et décline toute responsabilité quant à leur utilisation. Vérifiez dans le
jeu avant une décision importante.
